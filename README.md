# LibReserve - Library Book Reservation System

A simple responsive two-page library reservation website made with:
- HTML
- CSS
- JavaScript

## Files
- index.html: Landing/Home Page
- reservation.html: Book Reservation Form
- style.css: Responsive design and layout
- script.js: Mobile menu and client-side form validation
- github_link.txt: GitHub link submission file

## How to run
Open `index.html` in a browser.

## Assignment requirements covered
- Responsive navigation with 4+ links
- Mobile hamburger menu
- Hero section with primary and secondary buttons
- 3 feature cards
- Footer with contact/social links
- Reservation form with 7+ fields
- 5+ input types
- Required-field validation
- Email validation
- Phone pattern rule
- Password length rule
- Cross-field/date validation
- Field-level error messages
- Submit and Reset buttons
- Success summary shown on valid submission
- No backend required
